# Alan Lawrey Portfolio

This is my portfolio website that is designed to be statically hosted.

It was made using my own [virtual DOM](https://www.npmjs.com/package/simple-tsx-vdom) as a non-trivial example of using that framework. The information about myself, my work history and side projects are hardcoded in the `src/data/` folder.

Updating the page is done using:

``` bash
npm run build
git commit -m "Updated site"
git push
```

This will add an updated built static version of the site into the `docs/` folder and that is hosted currently by GitHub.
